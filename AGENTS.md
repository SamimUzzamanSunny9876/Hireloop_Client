# HireLoop client

Next.js 16 App Router + React 19 + Tailwind v4 + shadcn (`base-nova`) + better-auth/MongoDB. Uses npm (`package-lock.json`). No `src/` directory; `@/*` maps to the repo root. There is no test suite, test runner, or CI workflow — don't invent test commands.

## Commands

- `npm run dev` — dev server at `http://localhost:3000`.
- `npm run typecheck` — `tsc --noEmit`. Currently passes; run after changes.
- `npm run lint` — flat-config ESLint over the repo (`eslint`, no file args). Known pre-existing failures in `components/ui/carousel.tsx` and `hooks/use-mobile.ts` (`react-hooks/set-state-in-effect`); don't let those mask new issues.
- `npm run format` — Prettier for `**/*.{ts,tsx}` only (not CSS/JSON/MJS). Configuration is non-default: no semicolons, double quotes, LF, width 80, and Tailwind classes are auto-sorted using `cn`/`cva` and `app/globals.css`.
- `npm run build` — production build.

## UI and styling

- shadcn is configured with style `base-nova` in `components.json`: primitives come from `@base-ui/react`, not Radix. Add components with `npx shadcn@latest add <name>`; they land in `components/ui/`.
- Tailwind v4 is CSS-first in `app/globals.css` (`@import "tailwindcss"`, `@theme inline`). There is no `tailwind.config.*`; add theme tokens there.
- `lib/utils.ts` re-exports `cn` from the `cn` npm package. Existing shadcn files may import `cn` directly from `"cn"` instead; both work.
- Images live in `app/images/` and are imported statically for `next/image`. `types/next-images.d.ts` supplies the PNG module types because the generated `next-env.d.ts` is gitignored.
- Dark mode is class-based via `components/theme-provider.tsx`; pressing `d` toggles it (ignored while typing).

## Auth (better-auth + MongoDB)

- Server config: `lib/auth.ts`. Client: `lib/auth-client.ts`. Catch-all route: `app/api/auth/[...all]/route.ts` — keep this path or better-auth's client calls break.
- MongoDB is hard-coded to local `mongodb://localhost:27017/database`, database `Hireloop`; no `MONGODB_URI` env is read. Local MongoDB must be running for auth to work.
- Env lives in gitignored `.env`: `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `GITHUB_CLIENT_ID`/`GITHUB_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET`. Both social providers are always registered, so missing values break auth.
- `lib/auth-client.ts` creates two clients: `authClient` gets `BETTER_AUTH_URL`, but the exported `signIn`/`signUp`/`useSession` come from a separate `createAuthClient()` with no base URL. Also note non-`NEXT_PUBLIC_` vars are not available in browser code.
